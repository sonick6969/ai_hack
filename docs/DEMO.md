# Сценарий защиты — до 15 минут

Понадобятся локальный сервер, Chrome и предоставленный Excel. Перед защитой выполните команды README. Для отдельной чистой демонстрации используйте новый `DATABASE_PATH`; существующую рабочую базу не удаляйте. Интернет и LLM для сценария не нужны. В заранее подготовленной базе держите исходные 23 сообщения без объединения, а демо-примеры загружайте только по явному выбору.

## Запасной текст, если жюри просит пример

Отправитель: `Кафе «Угол», новая смена`.

> На С100, s/n 119, со вчера кофе наливается медленно. Работ не было. До этого всё было нормально.

Это запасной пример, а не незнакомый внешний тест. Зафиксируйте в защите, кто дал текст. У машины есть история исправления подачи воды; она не доказывает текущую причину. Нужны подтверждение машины/адреса, момент начала, работы перед симптомом и явный план. Для проверки реального резерва можно подготовить F010 со склада Тулы, при этом не утверждать, что фильтр сломан.

## Если что-то идёт не так

- Ошибка загрузки: показать строку/ячейку в отчёте, исправить Excel или использовать кнопку исходного файла.
- Нет связи с сервером: восстановить `bash scripts/dev.sh`, нажать обновление; не повторять изменения вслепую.
- LLM недоступна: локальный режим остаётся рабочим; не обещать живую LLM-демонстрацию без ключа.
- Недостаточно сведений или деталей: показать блокировку и черновую карточку, а не обходить проверку готовности.
- Нет принтера: «Печать / PDF» открывает стандартный диалог; сохранение PDF проверено в headless Chrome.
