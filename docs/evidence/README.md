# Доказательства проверки

Файлы сохранены из фактически выполненного финального прогона 12.11.2026. Данные вымышленные, из кейса и автоматизированных проверочных обращений.

- `backend-tests.txt` — вывод 69 проверок Python.
- `browser-tests.txt` и `browser-results.json` — вывод и структурированный результат 8 сценариев Chrome.
- `workflow-measurement.json` — автоматически введённый текст и время робота, не время человека.
- `engineer-card.pdf` — PDF, созданный из страницы печати через ссылку в интерфейсе.
- `prepared-card.png`, `queue.png`, `mobile-detail.png`, `import-report.png` — реальные скриншоты; не дизайн-макеты.
- `manifest.json` — контрольные суммы источника и файлов.

Скриншот/PDF показывают готовую версию до добавления проверочного уточнения. В конце теста уточнение снимает подготовку, а собственный резерв освобождается. Данные тестовой базы не заменяют рабочую базу. Повторить: `bash scripts/test_browser.sh` из корня проекта.
